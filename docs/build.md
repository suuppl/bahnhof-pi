# `build/` — CMake Build Output

Generated by CMake and not committed to version control.

## Contents after a successful build

```
build/
├── iris_fetch          # aarch64 ELF — DB IRIS timetable poller
├── weather_fetch       # aarch64 ELF — Open-Meteo weather poller
├── brightness_ctl      # aarch64 ELF — plugin: HDMI DDC/CI backlight curve
├── presence_ctl        # aarch64 ELF — plugin: radar presence → screen on/off
├── bahnhofstafel       # aarch64 ELF — LVGL framebuffer display
└── CMakeCache.txt      # Cached CMake variables (toolchain paths etc.)
```

## Rebuilding

```sh
make clean   # removes build/
make build   # runs cmake configure + cmake --build
```

Or manually:

```sh
cmake -B build -DCMAKE_TOOLCHAIN_FILE=aarch64-toolchain.cmake -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

## Native build (syntax check without Pi)

```sh
cmake -B build-native && cmake --build build-native -j$(nproc)
```

Uses system `find_package` for dependencies. Useful for catching compile errors locally.

## Build dependencies (on host)

- `aarch64-linux-gnu-gcc` (from `gcc-aarch64-linux-gnu` package)
- `cmake` ≥ 3.16
- No target libraries needed on host — they come from `sysroot/`
